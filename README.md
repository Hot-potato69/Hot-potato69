## About

I'm a cybersecurity student learning both red team (offense) and blue team (defense). My preference is red team, because I like understanding how systems get broken. I also study blue team, since the best attackers understand detection and the best defenders understand attackers.

I write Python, C++, Java, JavaScript and SQL, and I build small tools to understand what's under the hood.

> I only test systems I own or have written permission to test: my own labs, intentionally vulnerable machines, and legal CTF platforms.
